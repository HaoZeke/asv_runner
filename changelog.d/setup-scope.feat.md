Timing benchmarks accept ``setup_scope``. ``"call"`` (the default) keeps the 0.3 behavior: with a setup hook, auto-calibrated ``number`` stays 1 and an explicit ``number`` re-runs setup between individually timed calls. ``"sample"`` restores per-sample setup with plain ``timeit`` batching, so auto ``number`` is calibrated to ``sample_time``. The attribute is read from the same sources as ``number`` (benchmark function, class, then module).
